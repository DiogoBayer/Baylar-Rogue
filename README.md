# Baylar Rogue

Roguelike de ação em tempo real, em 2.5D, feito em **Godot 4.7 com C#**.

> Protótipo em desenvolvimento: uma sala com ondas de inimigos (guerreiros e magos), com combate de golpe em leque e dash.

## Como jogar

1. Instale o [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) e o [Godot 4.7.2 .NET](https://godotengine.org/download) (no Windows: `winget install Microsoft.DotNet.SDK.8` e `winget install GodotEngine.GodotEngine.Mono`).
2. Clone o repositório e dê dois cliques em `Jogar.bat`.

| Tecla | Ação |
| --- | --- |
| W A S D | Andar |
| Mouse | Mirar |
| Clique / J | Atacar |
| Espaço | Dash |
| R | Recomeçar |
